Zenvixo cPanel আপডেট

ফাইল:
- index.html: ওয়েবসাইট
- admin.html: আলাদা অ্যাডমিন প্যানেল

ইনস্টল:
১. cPanel > File Manager > public_html খুলুন।
২. আগের index.html ও admin.html ব্যাকআপ রাখুন।
৩. এই ZIP-এর index.html ও admin.html public_html-এ আপলোড করে Extract/Replace করুন।
৪. ওয়েবসাইট রিফ্রেশ করুন। Admin Panel বাটন থেকে অ্যাডমিন প্যানেল খুলুন।

পরিবর্তন:
- অ্যাডমিন প্যানেলে দৃশ্যমান Demo/Demo Mode লেখা সরানো হয়েছে।
- প্রোফাইল এবং Refer & Earn অংশের Referral Code কপি ফাংশন উন্নত করা হয়েছে।
- কপি করার জন্য Android WebView/পুরোনো ব্রাউজারের fallback যোগ করা হয়েছে।

গুরুত্বপূর্ণ:
এই HTML সংস্করণটি এখনো browser localStorage-ভিত্তিক। বাস্তব বহু-ইউজার সিস্টেম, নিরাপদ অ্যাডমিন লগইন, সার্ভার-সাইড পেমেন্ট সেটিংস ও ডেটাবেসের জন্য PHP/MySQL backend প্রয়োজন।
